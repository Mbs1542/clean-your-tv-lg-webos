## संस्करण चुनें

No-root और Root अलग-अलग टीवी सेटअप के लिए समान दर्जे के विकल्प हैं। LG Developer Mode के लिए No-root चुनें या पहले से root SSH पहुँच होने पर Root चुनें। संगतता और किए गए परीक्षणों का दायरा हर संस्करण के लिए अलग है।

- **No-root:** LG Developer Mode और Key Server चालू करें। टीवी पर दिखाया पासफ़्रेज़ भरें और टीवी पर आने वाला अलग पेयरिंग अनुरोध स्वीकार करें। Developer Mode सक्रिय रहना चाहिए; अवधि समाप्त होने पर इस तरीके से लगाए ऐप हट सकते हैं। Beta नवीनीकरण चालू होने पर भी आधिकारिक टाइमर देखें। Helper की निगरानी के लिए स्थानीय नेटवर्क चाहिए।
- **Root:** पहले से काम करता root SSH प्रवेश आवश्यक है। इंस्टॉलर टीवी को root नहीं करता। पहले से root किए टीवी पर Developer Mode चालू न करें। root प्रवेश और पुनर्प्राप्ति सेवाएँ उपलब्ध रखें।

Root के लिए Settings Service और System Profile (`com.webos.service.systemprofile`) के Home इंटरफ़ेस काम करने चाहिए; केवल root पहुँच से अनुकूलता की पुष्टि नहीं होती।

## स्थापना से पहले

टीवी चालू रखें और कंप्यूटर को उसी भरोसेमंद स्थानीय नेटवर्क से जोड़ें। बाद में कंप्यूटर बंद रह सकता है। अनुकूलता मॉडल, फ़र्मवेयर और रिमोट पर निर्भर है। Root के लिए वास्तविक उपकरण पर कुछ जाँच बाकी हैं।

No-root Helper को टीवी पर Node.js **0.12.2+** चाहिए। Root को Node.js **8+** और काम करता Python **3.9+** चाहिए। आवश्यकता होने पर इंस्टॉलर सत्यापित निजी Python डाउनलोड करता है; शुरुआती तैयारी के लिए **320 MiB** खाली जगह चाहिए। यह सिस्टम Python नहीं बदलता। पुनर्प्राप्ति के काम आने वाले रनटाइम सुरक्षित रखें। [Python (अंग्रेज़ी)](../OPTIONAL-PYTHON.md)। Developer Mode स्वतः नवीनीकरण **Beta है और डिफ़ॉल्ट रूप से बंद है**। बिना root टीवी पर वास्तविक नवीनीकरण की पुष्टि नहीं हुई है; आधिकारिक टाइमर देखते रहें।

### Developer Mode सेटअप (No-root)

Developer Mode से CYTV बिना root वाले TV पर ऐप इंस्टॉल कर सकता है।

1. TV पर LG Apps खोलें, Developer Mode खोजें और इंस्टॉल करें।
2. Developer Mode खोलें और अपने LG Developer खाते से साइन इन करें। ज़रूरत हो तो webostv.developer.lge.com पर खाता बनाएँ।
3. Dev Mode Status चालू करें। TV फिर से शुरू होगा। उसके बाद Developer Mode दोबारा खोलें।
4. Key Server चालू करें और Developer Mode खुला रखें। वहाँ दिखा IP Address ही CYTV में डालने वाला TV का पता है।
5. TV के Developer Mode में दिखे छह अक्षरों वाला Passphrase डालें। बड़े और छोटे अक्षर जैसे दिखें वैसे ही लिखें।

LG खाते का पासवर्ड नहीं, TV पर दिखा कोड डालें। कोड न दिखे तो Key Server चालू करें।

पेयरिंग अलग चरण है: TV पर अनुरोध आने पर रिमोट से CYTV को अनुमति दें।

Developer Mode चालू रखें: समय खत्म होने से पहले इसे खोलें और TV के इंटरनेट से जुड़े होने पर EXTEND दबाएँ। समय खत्म होने पर LG ये ऐप हटा सकता है।

## स्थापना और भाषा

- **Windows x64:** `cytv-windows-x64-desktop.zip` डाउनलोड करें, फ़ाइल एक्सप्लोरर में **Extract All** चुनें, फिर `cytv-desktop/cytv-desktop.exe` खोलें। `_internal` फ़ोल्डर उसके साथ रखें। Windows प्रकाशक हस्ताक्षर कॉन्फ़िगर नहीं है। अलग कंसोल `cytv-windows-x64.exe` है; नीचे के PowerShell आदेशों के लिए इसका नाम `cytv.exe` रखें और `.\cytv.exe` चलाएँ।
- **macOS 13 या नया:** Apple Silicon के लिए `cytv-macos-arm64.zip`, Intel के लिए `cytv-macos-x64.zip` खोलें। `cytv.app` को Applications में रखें और खोलें। स्थानीय नेटवर्क की अनुमति दें। भरोसेमंद डाउनलोड रुकने पर Privacy & Security → Open Anyway चुनें; Gatekeeper बंद न करें। पुराने सिस्टम की जाँच पूरी नहीं हुई है।
- **Linux x64:** Ubuntu 22.04+, Debian 12+ या Mint 21+ पर `cytv-linux-x64.deb` को ग्राफ़िकल पैकेज प्रबंधक से स्थापित करें और ऐप मेनू से Clean Your TV खोलें। लाइब्रेरी के लिए इंटरनेट लग सकता है। Linux ARM पैकेज नहीं है। अलग `cytv-linux-x64` निष्पादन फ़ाइल CLI है; ग्राफ़िकल ऐप के लिए `.deb` लें।

[Android इंस्टॉलर (अंग्रेज़ी)](../../android/README.md): ऊपर दाईं ओर भाषा चुनें। ऐप हटाए या डेटा मिटाए बिना अपडेट करें। Android 7 / WebView 108 न्यूनतम आवश्यकता है, सत्यापित फ़ोन नहीं; स्वीकृति Android 15 ARM64 / WebView 124 एमुलेटर पर हुई। वास्तविक फ़ोन और वास्तविक टीवी से जुड़ी पुनर्प्राप्ति सत्यापित नहीं हैं।

डेस्कटॉप सहायक शुरू में सिस्टम की भाषा चुनता है और आपकी चुनी भाषा सहेजता है। टीवी पर **सेटिंग्स → भाषा** में भाषा चुनें या टीवी की भाषा अपनाने वाला स्वचालित विकल्प चुनें। इंस्टॉलर और टीवी की भाषा सेटिंग अलग हैं। कोड [भाषा सूची](../LANGUAGES.md) में हैं।

macOS/Linux पर अलग से डाउनलोड की CLI के लिए, निकाली गई फ़ाइलों के फ़ोल्डर में:

```sh
chmod +x cytv
./cytv --language hi install
```

टीवी चुनें या उसका IP भरें, संस्करण चुनें और सारांश जाँचें। नई SSH पहचान केवल भरोसेमंद नेटवर्क पर अपने टीवी के लिए स्वीकार करें; सहेजी गई कुंजी बदलने पर प्रवेश रुकता है। Root पुनर्प्राप्ति तैयार करके Home तुरंत चालू करता है; परीक्षण अवधि या बनाए रखने की पुष्टि नहीं है। दिशा बटन, OK, Home, वापस/रद्द, आवाज़, स्टैंडबाय से वापसी और पूरी बिजली बंद करके दोबारा चालू करने की जाँच करें।

## उपयोग और पुनर्प्राप्ति

दिशा बटन से चुनें, OK से खोलें; क्रम बदलने के लिए OK दबाए रखें। वापस का छोटा दबाव ऐप का नेविगेशन और बाहर निकलने की पुष्टि बनाए रखता है। Home नियंत्रण चालू हो तो छोटा Home लॉन्चर खोलता है। वापस बटन 1.2 सेकंड दबाए रखने से LG Home एक बार खुलता है। Home नियंत्रण का स्विच और आपकी सेटिंग्स नहीं बदलते।

**दो सेकंड में Home तीन बार दबाएँ**, हर बार बटन छोड़ें। इससे पसंद मिटाए बिना LG Home लौटता है और नियंत्रण रुकता है। पुराने No-root Helper 0.6.13 तक इसके बजाय Home लगभग दो सेकंड दबाए रखें। Home दबाए रखना Root की आपातकालीन क्रिया नहीं है।

No-root: Home नियंत्रण फिर शुरू करने के लिए Home Helper खोलें, Helper शुरू करें चुनें और पुष्टि करें। चुनी हुई Home स्क्रीन बनी रहती है। Root: फिर शुरू करने के लिए Home सेटिंग्स में **Home बदलें** चालू करें। **LG Home खोलें** से Home का गंतव्य बदले बिना LG Home एक बार खुलता है। LG Home को स्थायी गंतव्य बनाने के लिए **Home बदलें** बंद करें या `cytv restore` चलाएँ। दोनों नियंत्रक एक साथ न चलाएँ। समस्या दोबारा हो तो LG Home चालू रहने दें।

```sh
./cytv --language hi status
./cytv --language hi doctor --report
./cytv --language hi restore
./cytv --language hi uninstall
```

रुकावट के बाद दोबारा प्रयास से पहले `status` चलाएँ और लॉग रखें। `restore` ऐप हटाए बिना LG Home लौटाता है; `uninstall` हटाने से पहले बहाल करता है। Root पुनर्प्राप्ति डेटा जानबूझकर रखा जाता है; दोबारा स्थापना मजबूर करने के लिए उसे न मिटाएँ। रिपोर्ट साझा करने से पहले देखें; कुंजियाँ या प्रोफ़ाइल फ़ोल्डर प्रकाशित न करें।

## अपडेट और हटाना

कनेक्ट होने पर cytv स्थापित → शामिल संस्करण दिखाता है और पहली स्थापना, पुनः स्थापना तथा पुराने संस्करण पर जाने में अंतर बताता है। पुष्टि से पहले सारांश पढ़ें; `--yes` संगतता जाँच नहीं हटाता। काम करने वाले पैकेज और सेटिंग्स की निजी प्रतियाँ रखें। कंप्यूटर से पैकेज बदलने से पहले No-root Helper रोकें; पहले अनइंस्टॉल न करें। चालू Root पर केवल एक IPK न चढ़ाएँ: cytv की तय प्रक्रिया अपनाएँ। कंप्यूटर ऐप हटाने से टीवी ऐप नहीं हटते।

Home सेटिंग्स → सॉफ़्टवेयर अपडेट खोलें और पुष्टि से पहले संस्करण जाँचें। टीवी पर अपडेट और रोलबैक के लिए No-root संस्करण में भी **root, Homebrew Channel** और पहले से तैयार संगत अपडेट ढाँचा चाहिए। बिना root कंप्यूटर उपयोग करें। पूरे सिस्टम के अपडेट की तैयारी अलग स्पष्ट कार्रवाई है: [अपडेट (अंग्रेज़ी)](../UPDATES.md)। पुनर्प्राप्ति में सहेजा रोलबैक संस्करण देखें; बाद में किए सेटिंग्स बदलाव खो सकते हैं।

**पहले से स्थापित 1.3.0:** अनुमत फ़ाइल सूची बदलने के कारण मूल System Updater से 1.4.0 नहीं लग सकता। प्रयास बदलाव से पहले रुक गया हो तो उसका रिकॉर्ड रखें और रुकें; स्थिति न मिटाएँ, बिना जाँच फिर न चलाएँ। स्थानांतरण के लिए जाँच वाली पुनर्प्राप्ति और नई 1.4.0 स्थापना उपयोग करें; केवल ऐप अपडेट सुरक्षित Root ड्राइवर नहीं बदलता। अगला OTA सुधार **अभी प्रकाशित नहीं है**। [स्थानांतरण और पुनर्प्राप्ति (अंग्रेज़ी)](../UPDATES.md#one-time-computer-preparation)।

Root HDMI आवाज़ पुनर्प्राप्ति प्रयोगात्मक है और **डिफ़ॉल्ट रूप से बंद है**; जरूरत होने पर ही चालू करें। यह ठीक चल रही आवाज़ रोक सकती है और eARC संगतता सिद्ध नहीं करती। [आवाज़ पुनर्प्राप्ति (अंग्रेज़ी)](../development/ROOT-AUDIO-RECOVERY.md)। अलग **Homebrew CYTV Installer अभी जारी नहीं हुआ है**; प्रकाशित कंप्यूटर या Android इंस्टॉलर उपयोग करें।

केवल अप्रकाशित उम्मीदवार: यदि पुराने Root फ़ोल्डरों की लिखने की अनुमति से फ़र्मवेयर API पहुँच रुकती है, तो `cytv enable-firmware-access --edition root --repair-package-permissions` वर्तमान पैकेज को विश्वसनीय निजी रिकॉर्ड से जाँचकर केवल Root के अपने पथों से समूह/अन्य की लिखने की अनुमति हटाता है। अज्ञात या बदली फ़ाइल पर मरम्मत रुकती है। प्रोफ़ाइल, Home चयन और फ़र्मवेयर अवरोध सेटिंग सुरक्षित रहते हैं। [विवरण (अंग्रेज़ी)](../LG-FIRMWARE-UPDATES.md#explicit-package-permission-repair-candidate).

केवल अप्रकाशित उम्मीदवार में: `cytv recover-system-rollback --edition root` उस जाँचे गए Root रोलबैक के लिए है जिसमें सभी पैकेज इंस्टॉलर पूरे हुए, लेकिन लॉन्चर की तैयारी की समयसीमा समाप्त हो गई। असली लॉन्चर का तैयारी संकेत जरूरी है; अज्ञात स्थापना परिणाम स्वीकार नहीं होते। पैकेज, तय कोड/कुंजियाँ, विफलता के प्रमाण और स्पष्ट रूप से बंद किया गया Home नियंत्रण सुरक्षित रहते हैं। सीमित प्रयास का निजी रिकॉर्ड रखा जाता है। सामान्य पुनः प्रयास समयसीमा नहीं बढ़ाता। पिछले 120 सेकंड समाप्त होने के बाद ही, बिना स्वीकृत तैयारी संकेत या अज्ञात स्थापना परिणाम के, `--new-recovery-attempt` पूरा पिछला रिकॉर्ड उसके UUID/हैश के साथ सुरक्षित कर नया प्रयास शुरू करता है। पूरी हो चुकी पुनर्प्राप्ति फिर नहीं चलती; प्रयास अपने आप दोहराए नहीं जाते। [प्रक्रिया और सीमाएँ (अंग्रेज़ी)](../RECOVERY.md#root-system-rollback-readiness-candidate)।

केवल अप्रकाशित 1.4.1 उम्मीदवार: टीवी से Root अपडेट के लिए System Updater 1.1.1 चाहिए। टीवी OTA से पहले `cytv replace-system-updater --edition root` से 1.1.0 को स्पष्ट रूप से बदलें। केवल System Updater बदलता है; Root/Root Updater ऐप, पूरा प्रोफ़ाइल और Home चयन सुरक्षित रहते हैं तथा पुरानी स्थिति संग्रहित होती है। अज्ञात या अधूरे कार्य बदलाव रोकते हैं। यह शर्त No-root फ़ीड पर लागू नहीं है। [प्रक्रिया (अंग्रेज़ी)](../RECOVERY.md#replace-the-root-system-updater-candidate)।

## सहायता और विस्तृत निर्देश

असफलता या रुकावट के बाद स्थिति जाँचें और उसी प्रयास की निदान रिपोर्ट सहेजें। निर्देशित पुनर्प्राप्ति हटाने और दोबारा स्थापना की अलग पुष्टि लेती है। परिणाम अनिश्चित हो तो रुकें और निजी लॉग तथा पुनर्प्राप्ति फ़ाइलें रखें; फिर प्रयास मजबूर करने के लिए इन्हें कभी न मिटाएँ। [पुनर्प्राप्ति (अंग्रेज़ी)](../RECOVERY.md)। सहायता के लिए मॉडल, फ़र्मवेयर, संस्करण/एडिशन, इंस्टॉलर संस्करण, असफल चरण और अपेक्षित/वास्तविक व्यवहार बताएँ; साझा करने से पहले रिपोर्ट जाँचकर गोपनीय जानकारी हटाएँ।
